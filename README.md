# Модуль 2.5: витяжний вентилятор на апаратному таймері

Домашнє завдання курсу Embedded Basic: кожну годину вентилятор вмикається на 15 хвилин, вмикає й вимикає його переривання таймера.
Плата ESP32-S3-WROOM-1-N16R8, PlatformIO, Arduino.

Відео: [demo.mp4](demo.mp4)

## Схема

Розводка на макетці: [map.svg](map.svg). На макетці стоять ще деталі інших домашок.

```
Вентилятор = мотор:
GPIO13 -> 1 кОм -> база 2N2222A, емітер -> GND
колектор -> мотор -> +5 В
діод 1N400x паралельно мотору, смуга на +5 В

GPIO18 -> 220 Ом -> LED -> GND  (дублює стан)
```

## Що робить

Час задають макроси `FAN_PERIOD_S` і `FAN_ON_S`. Для налагодження година = 12 с, 15 хвилин = 3 с, пропорція та сама. Для справжньої роботи треба 3600 і 900.

Таймер перериває раз на секунду. ISR рахує секунди й сам перемикає піни, без `delay`. `loop()` лише друкує лог.

| Клавіша | Дія |
|---|---|
| `b` | заблокувати `loop()` на 5 с, щоб перевірити незалежність таймера |

## Результат

Без блокування: увімкнення 1,59 с, вимкнення 4,59 с, увімкнення 13,59 с, вимкнення 16,59 с. Тобто 3 с роботи й період 12 с.

Під час `b` лог запізнюється, бо `loop()` стоїть. Наприклад, вимкнення надруковане на 31,89 с, хоча за графіком воно на 28,59 с. Наступні перемикання далі йдуть за графіком: 37,59 с і 40,59 с. Отже, графік від `loop()` не залежить.

Значення 3600 і 900 не запускав, перевірено лише стиснутий час.

## Запуск

```
pio run -t upload -t monitor
```
